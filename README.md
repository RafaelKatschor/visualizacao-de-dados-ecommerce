# Visualização de Dados - E-commerce

Projeto de análise exploratória de dados de um e-commerce utilizando Python, pandas, matplotlib e seaborn.  
O objetivo é ler o arquivo `ecommerce_estatistica.csv`, explorar os dados e gerar diferentes tipos de gráficos para destacar informações relevantes.

## Gráficos gerados
- Histograma (Distribuição dos preços)  
- Dispersão (Nota vs Preço)  
- Mapa de calor (Correlação entre variáveis numéricas)  
- Barra (Preço médio por marca)  
- Pizza (Distribuição por gênero)  
- Densidade (Distribuição dos preços)  
- Regressão (Nota vs Quantidade Vendida)  

## Tecnologias utilizadas
- Python 3.x  
- pandas  
- matplotlib  
- seaborn  

## Como executar
Clone este repositório, instale as dependências com `pip install pandas matplotlib seaborn`, certifique-se de que o arquivo `ecommerce_estatistica.csv` está na raiz do projeto e execute o script com `python visualizacao_de_dados.py`.

## Estrutura do projeto
├── ecommerce_estatistica.csv
├── visualizacao_de_dados.py
└── README.md



## Resultados
Os gráficos gerados permitem identificar padrões de comportamento dos consumidores, relação entre preço e avaliação, além de insights sobre categorias e marcas.
